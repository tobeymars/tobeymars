## 🚀 Dự án đã thực hiện

### 1. Hệ thống chấm công và quản lý nhân sự tích hợp Hikvision
- Phát triển hệ thống quản lý nhân viên và chấm công bằng Laravel.
- Tích hợp thiết bị kiểm soát ra vào Hikvision thông qua ISAPI.
- Xây dựng chức năng đồng bộ dữ liệu chấm công từ thiết bị.
- Thiết kế hệ thống phân công lịch làm việc, ca làm và tính công.
- Phát triển RESTful API và tài liệu API với Swagger.
- Xây dựng giao diện quản trị bằng Laravel Blade.

**Công nghệ:** PHP, Laravel, MySQL/MariaDB, RESTful API, Swagger, Hikvision ISAPI.

### 2. Website đặt lịch khám nha khoa
- Xây dựng website hỗ trợ khách hàng đặt lịch khám trực tuyến.
- Phát triển các chức năng quản lý lịch hẹn, thông tin khách hàng và dịch vụ nha khoa.
- Hỗ trợ nha sĩ quản lý lịch khám và thông tin bệnh nhân.
- Thiết kế cơ sở dữ liệu phục vụ hoạt động của hệ thống.

**Công nghệ:** PHP, Laravel, MySQL, HTML, CSS, JavaScript.

### 3. Phần mềm kế toán FreeWayKeiri
- Tham gia thực tập và tìm hiểu sản phẩm kế toán FreeWayKeiri.
- Làm việc với các chức năng nhập và xuất dữ liệu.
- Hỗ trợ xử lý dữ liệu và thống kê.
- Làm việc với chức năng xuất báo cáo Excel.

**Lĩnh vực:** Phần mềm kế toán, xử lý dữ liệu, Excel.

### 4. Hệ thống quản lý an toàn thực phẩm trường học
- Tham gia phát triển giao diện website quản lý.
- Xây dựng và chỉnh sửa các thành phần giao diện.
- Hướng đến trải nghiệm người dùng đơn giản, trực quan và dễ sử dụng.

**Công nghệ:** JavaScript, HTML, CSS.
